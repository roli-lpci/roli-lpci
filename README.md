## What I Do

**[AI Behavioral Audit](https://hermes-labs.ai)** — I test enterprise LLM deployments for structural reasoning failures that create liability exposure. Four failure modes no other vendor tests for: domain-specific sycophancy, null-result bias, hermeneutic drift, and intent exceptionalism. My methodology (Twin-Environment Simulation) requires no production access — just your system prompt and model choice.

**[Context Engineering Diagnostics](https://hermes-labs.ai/#research)** — I scan AI agent configurations for structural failure patterns before deployment. 7 case studies, 6+ PRs submitted to major AI frameworks, 92+ issues mapped across 12 repos.
